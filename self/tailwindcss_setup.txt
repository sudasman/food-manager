create a folder to contain input.css
add @import "tailwindcss"; to it
run npx @tailwindcss/cli -i ./folder_name/input.css -o ./folder_name/output.css --watch
cargo add tower_http --features full

add to html <link rel="stylesheet" href="/css/output.css">
