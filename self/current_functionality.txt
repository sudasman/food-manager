used axum to set up a connection with my localhost
initialized a database connection with sqlx
created the frontend "home.html" using html and created a link between the frontend with the backend using askama
the backend receives information from Form in the form of sequences (Vecs) and individual data (String, i32)
this data is collected into their corresponding vectors which is then saved into the database
the page is refreshed after, so GET is invoked and the page is updated with any new recipes added
the GET method simply stores corresponding data from the database into their respective vectors and then initialzed as the fields of the template struct 
the template struct, which uses a vector as its field, displays all recipes recieved so far
